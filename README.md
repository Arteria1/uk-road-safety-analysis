# UK Road Safety Analysis

## Project Overview

This project analyses UK road collision data to identify trends,
high risk groups and factors associated with serious road casualties.

The project will use SQL, Python and Power BI to transform raw
government data into actionable road-safety insights.

## Key Questions

- How have collisions changed over time?
- When are serious collisions most likely to occur?
- Which road users are most at risk?
- Which areas experience the highest levels of serious casualties?
- What environmental conditions are associated with severe collisions?
